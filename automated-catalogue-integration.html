Home Automated Catalogue Integration

This project automates syncing Shopify product data to MetaCommerce via a secure, cloud-hosted CSV feed. It handles large product catalogues, custom attributes (e.g., WhatsApp-friendly descriptions), and ensures regular, automated updates with minimal manual intervention.

Problem Statement

The default Shopify Facebook and Instagram plugin only synchronises the standard product description, which is unsuitable for WhatsApp catalogues. Manual uploads to MetaCommerce were time-consuming and error-prone, and sensitive product information needed secure delivery without public exposure.

Solution

I built a fully automated pipeline that:

  • Fetches Product Data from Shopify
    • Integrated a custom Shopify app to pull product details, including WhatsApp-friendly descriptions. Normalises and formats data for MetaCommerce.
  • Automates Feed Generation (Python)
    • 'feed_generator.py' generates the CSV feed. Dependencies and environment variables are securely managed via 'requirements.txt' and GitHub secrets.
  • Uploads Feed to Cloudflare R2 (Python)
    • 'upload_to_r2.py' uploads the feed to a secure Cloudflare R2 bucket. Bucket access is protected using API keys stored as GitHub secrets.
  • Serves Feed via Cloudflare Worker (JavaScript)
    • Provides secure serverless access to the CSV feed with basic authentication, caching, and error handling. Exposed via a custom subdomain
  • Automates Scheduling (GitHub Actions)
    • Workflow runs every 5 hours to generate and upload the feed. MetaCommerce consumes the feed hourly through the secured URL.
Key Features
  • Automated & Scalable: Fully hands-off workflow with scheduled updates.
  • Secure Feed Delivery: Basic auth and API-key protection; no public credentials exposed.
  • Custom Product Attributes: Supports WhatsApp-friendly descriptions and other metadata.
  • Serverless Architecture: Low-cost, lightweight cloud hosting via Cloudflare R2 and Workers.
  • Monitoring & Debugging: Logs and debug info enable handling of incremental updates or full catalogue refreshes.
Challenges & Solutions
  • Secure storage: Cloudflare R2 with service account credentials stored in GitHub secrets.
  • Access control: Cloudflare Worker with basic authentication ensures only MetaCommerce can access the feed.
  • Custom product attributes: Default Shopify plugin insufficient; required a custom app.
  • Incremental updates: Pipeline designed to handle single-product updates or full catalogue refreshes.
Outcome

Fully automated, secure, and scalable product feed from Shopify to MetaCommerce. Eliminated all manual work for feed updates, with feed accessible only to MetaCommerce and supporting WhatsApp-friendly catalogue presentation.

Tools & Technologies Used

Python, JavaScript (Cloudflare Workers), Shopify API, GitHub Actions, Cloudflare R2, MetaCommerce Feed API
